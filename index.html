Welcome to Roland Script

Roland Script (or Roland) is a DSL designed to be simple yet powerful. It is ideal for structured scripting with minimal syntax.

Basic Script Structure

ROLAND SCRIPT
hi roland.script! // Entry point of the script (MANDATORY) end! // The word is not mandatory, but it's used to make the code clean at the end. pass! // Also, the word is not mandatory, but it is used to make the code clean in the end.

Variables - Integers

ROLAND SCRIPT
var = X; // Declare integer variable X = 3; // Assign value

Variables - Decimals (Dnumber)

ROLAND SCRIPT
Dnumber = X; // Declare decimal variable X = 3.4; // Assign decimal value

Variables - Characters

ROLAND SCRIPT
character = X; // Declare character variable (single letter) X = e; // Assign character (no quotes)

Variables - Words (Strings)

ROLAND SCRIPT
word = X; // Declare word variable X = ammar; // Assign word (no quotes)

Variables - Boolean (TFvar)

ROLAND SCRIPT
TFvar = X; // Declare boolean variable (true/false) X = true; // Assign true or false

Prove - Immutable Constants v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
prove var = PI; PI = 314; // Once set, PI cannot be changed // prove with other types: prove word = APP_NAME; APP_NAME = Roland; prove TFvar = DEBUG_MODE; DEBUG_MODE = false; prove character = GRADE; GRADE = A; prove Dnumber = GRAVITY; GRAVITY = 9.81; // Trying to reassign a proved variable causes an error: // PI = 500; ← This will fail!

Arrays (line for class) v2.0

ROLAND SCRIPT v2.0
line for class:[Ammar, Ali, Ahmed,] // Define an array line for class = ("My Array") msg.log:("My Array")

Cletters - Character Combiner v2.0

ROLAND SCRIPT v2.0
Cletters message:("h e l l o w o r l d !") msg.log:("message") // Output: "helloworld!"

Mutable Variables

ROLAND SCRIPT
X = 34; // It can be changed after appointment

Greet - Reserve a Name

ROLAND SCRIPT
greet name:("ali") // Reserve a name in the code msg.log:("hello name")

Conditions (if)

ROLAND SCRIPT
var X = 3; if var X = ("3") msg.log:("Matched")

Greater than & Younger than v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
var = X; X = 3; var = Y; Y = 34; // Check if X is younger (less) than Y: if X younger than Y msg.log:("X is younger than Y") // Check if Y is greater than X: if Y greater than X msg.log:("Y is greater than X")

Logical Operators (and, or, xor, not) v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
var = A; A = 5; var = B; B = 10; var = C; C = 20; // and: both conditions must be true if A = 5 and B = 10 msg.log:("Both A and B match!") // or: at least one condition must be true if A = 5 or B = 99 msg.log:("A matches OR B would match!") // xor: exactly one condition must be true if A = 5 xor B = 99 msg.log:("Exactly one is true (A=5 yes, B=99 no)") // not: negates a condition if var A not 99 msg.log:("A is not 99") // Combining with greater/younger: if A greater than 2 and C younger than 30 msg.log:("Complex condition passed!")

Other & Wrong Other (Else & Else If) v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
var = SCORE; SCORE = 75; if SCORE greater than 80 msg.log:("Excellent!") other: msg.log:("Not excellent") wrong other: SCORE greater than 50 msg.log:("Good enough!") // other: acts like 'else' - runs if no condition matched. // wrong other: acts like 'else if' - checks another condition.

SLbell - Switch Case v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
var = DAY; DAY = 3; SLbell: value.1 msg.log:("Sunday") endSLbell! otherSLbell: value.2 msg.log:("Monday") endSLbell! otherSLbell: value.3 msg.log:("Tuesday") endSLbell! otherSLbell: value.4 msg.log:("Wednesday") endSLbell! otherSLbell: value.5 msg.log:("Thursday") endSLbell! // Default case if no value matches: if all fail or one fails msg.log:("Unknown day")

Range - Fast Repeater v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
var = X; X = 100; // Print X repeated 3 times: <range=3> for X; // Example with word variable: word = GREET; GREET = Hello; <range=5> for GREET; // Prints "Hello" five times.

ACT! - Reusable Functions v3.0 cancelled

ROLAND SCRIPT v3.0 cancelled
// Define an act! (function) named "sayHello": act! = ("sayHello") msg.log:("Hello from act!") msg.log:("This is reusable code.") repass! // REQUIRED to close the act! block // Define another act! with calculations: act! = ("calculate") get lib:("calculator") msg.log:("10 + 20 * 3") repass! // Call (run) the acts: act.run:("sayHello") act.run:("calculate") // IMPORTANT: Every act! MUST end with repass! // Otherwise you get: "You must enter the word repass! to close the act!"

User Input (if typed & msg.out)

ROLAND SCRIPT
msg.out:("Enter number:") if typed = ("34") msg.log:("You typed 34")

Input & Output (msg.log & msg.out)

ROLAND SCRIPT
msg.log:("Hello World!") // Print output to console msg.out:("Enter value") // Receive user input

Libraries (get lib) v2.0

ROLAND SCRIPT v2.0
get lib:("calculator") // Load calculator library (math.js powered) msg.log:("10 + 5 * 3") // Output: 25

Repeat / Reload (reload!)

ROLAND SCRIPT
msg.log:("hello world!") reload! = (19) // Repeat the previous command 19 times

Comments (bookname)

ROLAND SCRIPT
bookname:("this code for calculator") // Add a comment

Termination (PASS! & END!)

ROLAND SCRIPT
msg.log:("hello world!") pass! // Final Termination
